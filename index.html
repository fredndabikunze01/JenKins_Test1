How it works

From commit to production

Each change moves through the same automated stages.

1

Source

Code is pulled from the Git repository when changes are pushed.

2

Build

The application is compiled and packaged automatically.

3

Test

Automated checks catch problems before they reach users.

4

Deploy

The verified build is released to the web server.

Why CI/CD

Software delivery, simplified

Continuous Integration and Continuous Deployment make releasing software predictable.

Faster releases

Automation removes manual steps, so updates reach users in minutes instead of days.
